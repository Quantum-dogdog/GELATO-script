## CZ-5 轨道优化复现项目（基于日本航天组织开源的GELATO项目，该项目没做助推器的建模，故而芯一级与助推器采用的是加权平均法） — 版本演进总结

# 一、算例版本演进

cz5-tli-calib（v1）：约束仅为终端轨道根数（近地点 200 km / 远地点 41 万 km / 倾角 21.3°），SEIG 段 waypoint 为空约束；零风（cz5-wind-zero.csv）、基础气动表（cz5-CA.csv）。计算载荷 8801.4 kg，为物理理想化条件下的上限值。

cz5-prof1：v1 基础上增加 SEIG 段顶点约束（apex ≤ 182 km），依据为直播遥测 520 s / 554 s 实测高度。载荷 8251.0 kg。

cz5-prof2：顶点约束收紧至 178 km，风场替换为冬季风（cz5-wind-winter.csv）。载荷 8066.1 kg。相对 v1 下降约 735 kg，主要来源为风场与弹道剖面约束。

cz5-prof2-ca93：气动表替换为 1993 年版风洞数据（cz5-CA93.csv）。载荷 8131.0 kg。与基础表（cz5-CA.csv）结果对比，气动数据选择敏感度为 ±48 kg。

cz5-prof4：修正约束定义不完整问题——v1/prof2 仅约束终端高度，未约束速度，优化解存在亚轨道滑弧。prof4 增加 COAST 段 perigee_alt ≥ 180 km（等价于钉速度，由活力公式：r 固定时近地点高度与速度一一对应）与 BURN2 段 altitude ≥ 180 km（钉高度）。载荷 7911.5 kg。

cz5-prof5：近地点下限 180 → 195 km，进一步逼近 200 km 圆停泊轨道。载荷 7591.5 kg（−320 kg，圆度收紧代价）。

cz5-prof6：二子级推进剂 29100 → 31150 kg，验证终端约束已处于活跃边界。载荷 7955.9 kg，推进剂增量对载荷贡献趋零。

cz5-prof7：末段变体，载荷 7560.1 kg，为链条收敛终点。

# 二、参数敏感度

俯仰初值扫描（cz5-pit65 / pit75 / pit85）：三组载荷一致至 8658.532 kg，参数不敏感。

射向扫描（cz5-az98 / cz5-az108）：8659.2 / 8658.1 kg，倾角终端约束活跃，射向敏感度近零。

气动表：±48 kg，为主要敏感源。

风场：prof2 剖面约束下风场替换（cz5-wind-winter.csv vs 零风）载荷差 <0.1 kg，剖面约束主导时风不敏感。

# 三、仓库配套

analyze_calib.py：批量读取结果档案，输出各算例收敛状态与载荷对账。

compare_telemetry.py：计算弹道与遥测数据（520 s / 554 s 高度）对比。

数据文件：风场表 3 套（cz5-wind-zero / cz5-wind-winter / example-wind_average.csv）、气动表 2 套（cz5-CA / cz5-CA93）、settings 文件 10 套，全链条可复现。

# 结论

载荷由 8801.4 kg（v1，理想化）收敛至 7560.1 kg（prof7，全约束），差值约 1240 kg 的构成：风场与剖面约束约 −735 kg，速度/高度双重约束与圆度收紧约 −500 kg。载荷单调下降由约束逐步真实化解释，各档均收敛至可接受解，settings 与数据文件齐备，结果可复现。


# 工程教训

发散结果会经热启动文件自我传染：不收敛的解存为 output 后，若被下一发作为热启动源，错误解会沿链条传播。规程：跑前备份 output 目录，跑后先检查 EXIT 状态，非收敛结果禁止用作热启动源。

# GELATO 能力边界（实测确认）

无节流控制：throttle 为 settings 固定参数，dynamics 未实现推力调节。

无真实历元：ECI/ECEF 在 t=0 重合，发射时刻不进入模型。

仅轴向阻力：zero-lift CA，无 C_N/C_Y。

终端无 RAAN：轨道面由偏航制导决定，模型中无此自由度。

waypoint 受限：仅段起点，仅 exact/min/max，无效 mode 静默跳过。

段结构刚性：段定义中途更改导致热启动失效，冷启动发散。

定位：GELATO 为标称弹道优化器（单发、确定性、二体 + 推力 + 轴向阻力）。CZ-5 TLI 复现链（标定误差 +5.6% → ±1.6%）已达其能力上限。

# 下一步方向：运力网格扫描（对标 Silverbird Astronautics ascent calculator）

与 Silverbird 的定位差异：Silverbird 采用经验公式法（分级 ΔV 预算 + 拟合损失系数），秒级出全火箭库运力表，但对具体构型误差 5–10% 量级；本仓库为真实 3-DOF 弹道优化（推力曲线、质量账、气动库、风场、地球自转），损失由优化器积分而非拟合，精度上限高一档，代价是单点计算时间（热启动约 15 s，冷启动分钟级）。

相对 Silverbird 的增量输出：Max-Q、落区、下射程剖面；风场敏感性。
